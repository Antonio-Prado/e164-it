API

V1 endpoints (no auth yet). Everything returns UTF-8.

POST /v1/parse

curl -i -X POST https://e164.it/v1/parse \
  -H 'content-type: application/json' \
  -d '{
    "input": "0039 333 123 4567",
    "default_region": "IT",
    "options": {
      "format": ["e164","international","national","rfc3966"],
      "classify": true,
      "mask": {"mode":"last4"},
      "hash": {"enabled": false}
    }
  }'

POST /v1/batch/parse

Multipart CSV upload. Returns a CSV attachment.

curl -i -X POST https://e164.it/v1/batch/parse \
  -F "file=@sample.csv" \
  -F "phone_column=phone" \
  -F "default_region=IT" \
  -F "has_header=true" \
  -F "delimiter=auto" \
  -F "mask_mode=last4" \
  -F "hash_enabled=false" \
  -o e164_batch_results.csv

Notes: batch V1 limit is ~5MB per file. For bigger workloads we will add async jobs.
