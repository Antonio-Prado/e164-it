Privacy

Short version (V1): this tool is designed to avoid storing raw phone numbers.

  • The API processes input and returns normalized outputs.
  • By default, raw numbers are not meant to be persisted server-side.
  • Optional outputs include masked and HMAC hash (requires HASH_SECRET).
  • Batch results are generated on the fly and returned as a CSV download.

This page will be expanded when we add API keys, quotas, and async batch jobs.
